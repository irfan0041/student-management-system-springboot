# Student Management System (Spring Boot + Thymeleaf + MySQL)

A real-world **Spring Boot full-stack project** to manage student enrollments, course details, and academic records with a clean layered architecture, server-side form validation, dynamic pagination, and secure authentication.

This repository is **public for learning and portfolio reference**, built to demonstrate modern Java full-stack web development practices.

## 🛠️ Tech Stack

- **Java** (JDK 17+)
- **Spring Boot** (Spring MVC, Spring Security, Spring Data JPA)
- **Thymeleaf** (Server-side UI Template Engine)
- **MySQL** (Database)
- **Bootstrap 5** (Responsive Layout & UI)
- **Maven** (Dependency Management)

---

## ✨ Features

- ✅ **Authentication & Authorization** — Secure Login/Logout with Spring Security & Try Demo Account integration
- ✅ **Student Management (CRUD)** — Create, View, Update, and Delete student profiles
- ✅ **Server-side Validation** — Form inputs validated before persisting to database
- ✅ **Pagination & Sorting** — Efficient data handling for large student datasets
- ✅ **Clean Layered Architecture** — Clear separation with DTOs, Entities, Services, and Repositories
- ✅ **Global Exception Handling** — User-friendly error pages and custom validation messages
- ✅ **Responsive Dashboard** — Dynamic Thymeleaf UI with Bootstrap styling
